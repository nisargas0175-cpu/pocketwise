💸 PocketWise

Your Money. Your Goals. Your Future.

PocketWise is a personal finance management web application designed to help users track their income, manage expenses, monitor their balance, and develop smarter financial habits.

✨ Features

- 💰 Balance Overview — View your current balance at a glance.
- 📈 Income Tracking — Keep track of money received.
- 💳 Expense Tracking — Record and monitor your spending.
- 🧾 Transaction History — Review recent transactions.
- 🎨 Clean Interface — Enjoy a simple, user-friendly design.
- 📱 Responsive Layout — Access the application on different screen sizes.

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

🚀 Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open "index.html" in your web browser.
4. Start adding income and expenses.
